# Mon timbrage

Une calculette web simple pour saisir manuellement ses plages de travail et suivre son temps quotidien.

## Fonctionnalités

- ajout de plusieurs plages horaires par journée ;
- calcul automatique en heures/minutes et en heures centésimales (1/100e) ;
- comparaison avec un objectif journalier configurable (8,20 h par défaut, soit 8 h 12) ;
- calcul de l'heure de départ lorsque la dernière plage est ouverte ;
- historique hebdomadaire et export CSV ;
- données conservées localement dans le navigateur.

## Utilisation locale

Le projet ne nécessite aucune installation. Ouvrez simplement `dist/index.html` dans un navigateur moderne.
